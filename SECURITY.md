# Security

## Reporting a vulnerability

If you have repository access, report it privately: open <https://github.com/bretperry/shell-bouncer/security/advisories/new>.
If the advisory form is unavailable, contact the maintainer privately through a channel you already use. Do not post vulnerability details in a public issue.

Include what you ran, what you expected, and what happened. A reproduction helps most.

## What to expect

- This is a one-maintainer project. Reports are read as time allows; there is no response-time promise.
- A fix ships as a new patch release of `shell-bouncer`. The advisory credits you unless you ask it not to.

## Supported versions

Only the latest release of `shell-bouncer` gets fixes.

## Scope

Shell Bouncer is licensed under MIT (see `LICENSE`).
Bugs in your own configuration, or in tools it runs on your behalf, are outside its scope.
