# Security

## Reporting a vulnerability

Report it privately: open <https://github.com/bretperry/reins/security/advisories/new>.
Do not open a public issue for a vulnerability.

Include what you ran, what you expected, and what happened. A reproduction helps most.

## What to expect

- This is a one-maintainer project. Reports are read as time allows; there is no response-time promise.
- A fix ships as a new patch release of `reins`. The advisory credits you unless you ask it not to.

## Supported versions

Only the latest release of `reins` gets fixes.

## Scope

`reins` is source-available software under the Functional Source License (see `LICENSE`).
Bugs in your own configuration, or in tools it runs on your behalf, are outside its scope.
